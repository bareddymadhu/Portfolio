# Madhu Sudhan Reddy Portfolio

Responsive portfolio for:
- Software Developer
- Backend Developer
- Frontend Developer
- Full Stack Developer
- AI Engineer / AI Developer

## Run locally
Open `index.html` in a browser.

## Customize
1. Replace LinkedIn/GitHub links when you have the URLs.
2. Add project GitHub/demo links to each project card.
3. Add a PDF resume link if desired.
4. Replace or expand project descriptions with your final resume versions.

## Deploy
This static site can be deployed on GitHub Pages, Netlify, Vercel, or any static hosting service.
